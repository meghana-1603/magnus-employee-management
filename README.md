# Magnus Employee Management

A full-stack employee management application developed as part of the JALA Technologies Magnus developer task.

## Technologies Used
- **Frontend:** React.js, Vite, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Tools:** Git, GitHub, REST APIs

## Features

### Employee Management
- Create employee records
- Search employees
- Edit employee details
- Delete employee records
- Store employee data in MongoDB

### More Menu
- Multiple Tabs
- Menu
- Autocomplete
- Collapsible Content
- Images
- Slider
- Tooltips
- Popups
- Links
- CSS Properties
- iFrames

## Run Locally

### Backend
1. Open a terminal and navigate to the `server` directory.
2. Install dependencies using `npm install`.
3. Configure the MongoDB connection and environment variables.
4. Start the backend using the start script defined in `server/package.json`.

### Frontend
1. Open another terminal and navigate to the `client` directory.
2. Install dependencies using `npm install`.
3. Start the frontend using `npm run dev`.

## Project Purpose
This project demonstrates full-stack development, CRUD operations, REST API integration, database connectivity, and interactive UI features.
